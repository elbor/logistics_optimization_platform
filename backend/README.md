# backend

Laravel-моноліт: API для застосунку водія + адмін-панель на Filament.

Створено через `./bin/setup` (Laravel на PHP 8.4, база PostgreSQL + PostGIS).
PHP і Composer запускаються лише в Docker — команди див. у кореневому `CLAUDE.md`,
розділ «Команди». Обсяг і модель даних — `docs/SPEC.md` (розділи 3, 6, 7, 10).
