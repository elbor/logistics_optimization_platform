# Стек: Flutter + Laravel

Oct 27, 2026 · @Oleksandr Streltsov

Flutter для застосунку водія і Laravel (з Filament для адмінки) для бекенду — нудний у хорошому сенсі вибір: дві частини системи замість трьох і зріла екосистема на бекенді.

## Перевірка за чотирма питаннями

Обидві технології проходять перевірку; єдина ціна — друга мова в проєкті (PHP).

1. **Яку проблему розв'язує вибір?** Готового стеку ще немає, тож питання в іншому: що ти зможеш підтримувати сам. Правило — обирати те, чим впевнено користуєшся.
2. **Найдешевше рішення.**
   - **Flutter для застосунку водія.** Ти його вже знаєш, він покриває Android та iOS однією кодовою базою, MapLibre для Flutter активно підтримується. Підстав брати іншу технологію немає.
   - **Laravel для бекенду.** Зрілий фреймворк, у якому вже є все потрібне: міграції, авторизація, черги, планувальник задач, HTTP-клієнт для запитів до VROOM і OSRM.
3. **Вартість на п'ять років.** Laravel виграє в Serverpod: старший, більша спільнота, легко хоститься на будь-якому VPS, відповіді на типові проблеми вже є. Ціна — вивчення PHP.
4. **Хто чинитиме о третій ночі?** Ти. Тому частин системи має бути якомога менше.

## Головний аргумент: адмінка всередині Laravel

Адмін-панель робиться всередині Laravel через Filament, генератор адмінок, тож окремий застосунок для адмінки (Flutter Web чи React) не потрібен.

- **2 частини замість 3:** застосунок водія на Flutter і один моноліт на Laravel (API + адмінка).
- **Швидкий CRUD:** магазини, замовлення, водії, машини, фільтри й експорт у CSV робляться за години, а не дні.
- **Простіша авторизація:** адмін входить через серверні сесії, застосунок водія — через токени Sanctum. Обидва способи легко відкликати, на відміну від JWT.

## Що залишається за замовчуванням

Уся інфраструктура вміщується на одному сервері без додаткових сервісів.

| Потреба | Рішення |
| --- | --- |
| База даних | PostgreSQL + PostGIS, без Redis на старті |
| Черги | Драйвер `database` у Laravel, без окремого брокера |
| Розгортання | Один VPS з Docker Compose: Laravel, PostgreSQL, VROOM, OSRM |

## Застереження

- **Конструктор маршруту з картою** — єдиний екран адмінки, якого Filament не дає «з коробки». Карту з точками й перетягуванням порядку доведеться зробити окремим компонентом на MapLibre GL JS. Це найскладніший екран за будь-якого стеку.
- **PHP — нова мова.** Laravel вважається одним із найпростіших фреймворків для входу, і Claude добре з ним працює, але на навчання треба закласти час.
